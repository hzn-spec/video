还没有视频

三种方式任选其一,推荐后两种 —— 视频由平台或对象存储提供,不占用本机带宽。

videos/
  • ① 本地文件 —— 把视频放进上面的目录,刷新本页即可,不用重启服务。
    适合:局域网观看、本机带宽充裕(服务器 / 家宽)。
  • ② 外部直链(推荐) —— 视频放到对象存储或 CDN,用直链播放。
    VIDEO_URL=https://你的存储/视频.mp4 npm start
    适合:本机上行带宽小(校园网、4G),观众要秒开和流畅拖动。
  • ③ 平台嵌入(最省事) —— 直接把 B 站 / YouTube 的分享链接交给它。
    VIDEO_PAGE=https://www.bilibili.com/video/BV1xx411c7mD npm start
    适合:视频本来就要发到平台,顺便当播放源。

为什么推荐 ②③:如果本站跑在带宽很小的网络上,页面几 KB 能秒开, 但自己往外发视频会卡到不可用。把视频交给带宽充裕的地方托管,网站只做外壳最快。
